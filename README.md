#  Tatil & Seyahat Sitesi
Bu proje Murat Yücedağ'ın YouTube üzerinde yayınladığı "50 Derste Asp.Net Mvc ile Tatil & Seyahat Sitesi" playlist'inin reposudur.

# Projeye Genel Bakış
👤 Kullanıcı Arayüzü: Responsive, modern ve anlaşılır bir tasarım, ziyaretçilere blog yazılarını ve detaylarını listeliyor.
<br/>
🖱️ Admin Yönetim Paneli: Admin Anasayfadaki Bütün Tablolar için crud işlemleri gerçekleştirerek anasayfayı yönetebilir.

# Kullanılan Teknolojiler ve Uygulamalar
- 🤖 ASP.NET MVC
- 🎐  PartialView
- 🎡  Code First
- 💻 Microsoft SQL Server (MSSQL) Veritabanı
- 🎨 HTML-CSS-Bootstrap
- 🖌️ JS
- ⌨️ LINQ
